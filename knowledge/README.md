# Aniket Kumar Gupta — AI Avatar Knowledge Base

This folder contains six Markdown documents for a personal AI avatar / RAG knowledge base:

1. `personal_info.md`
2. `technical_skills.md`
3. `projects.md`
4. `experience.md`
5. `achievements.md`
6. `interview_answers.md`

## Suggested use
- Add these files to the knowledge directory used by your Node.js RAG backend.
- Rebuild / refresh your vector index after adding or editing documents.
- Keep facts current. In particular, verify CGPA, LeetCode count, project implementation status, and any new internship or certification before using them in an interview.

## Grounding policy
These documents intentionally avoid inventing unverified internships, employment, awards, certificates, users, revenue, or performance metrics. Update the files when you have verified details.
